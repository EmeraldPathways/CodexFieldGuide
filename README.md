# Codex Field Guide

An interactive, Mac-first course for learning Codex from setup to a tested capstone project.

## Run locally

Open `index.html` in a modern browser. Lesson progress, checks, quiz answers, and notes are saved in that browser on that device.

## Publish

This repository is configured to publish through GitHub Pages. The workflow deploys the static app after each push to `main`.

Expected URL: https://emeraldpathways.github.io/CodexFieldGuide/
